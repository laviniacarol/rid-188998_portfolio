📘 Visão do Projeto

PT-BR:
Este portfólio foi desenvolvido como parte da disciplina React com TypeScript. O objetivo é demonstrar habilidades em:

Criação de componentes funcionais com React

Tipagem estática utilizando TypeScript

Gerenciamento de estado e hooks do React

Estruturação modular e reutilizável de código

EN:
This portfolio was developed as part of the course React with TypeScript. The goal is to showcase skills in:

Building functional components with React

Static typing using TypeScript

State management and React hooks

Modular and reusable code structure


⚙ Funcionalidades

Exibição de informações pessoais e habilidades

Listagem de projetos desenvolvidos

Navegação entre seções utilizando React Router

Responsividade para dispositivos móveis

🖼 Demonstração

🧪 Como Rodar

Clone o repositório:

git clone https://github.com/laviniacarol/rid-188998_portfolio.git


Navegue até o diretório do projeto:

cd rid-188998_portfolio


Instale as dependências:

npm install


Inicie o servidor de desenvolvimento:

npm start


Abra o navegador e acesse:

http://localhost:3000
